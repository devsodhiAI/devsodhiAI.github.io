Privacy Policy: PGQ uploader

Last updated: October 2026

PGQ uploader is a personal tool used only by the owner of the Pretty Good Question YouTube channel to upload and schedule that channel's own videos.

What it accesses

With the channel owner's permission, it uses the YouTube Data API scope that allows uploading videos and setting their thumbnails on the owner's own channel. It does not read, collect or store data about any other person.

What it stores

The sign-in token Google issues is stored only on the channel owner's own computer. Nothing is sent to any server other than Google's YouTube API, and no data is sold or shared.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The app's use of YouTube API Services is also subject to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions.
